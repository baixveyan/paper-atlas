# A Unified Framework for Knowledge Transfer in Bidirectional Model Scaling

核对日期：2026-11-08。正文与配图按v2重审。以下实验均为作者报告；本地完成原文阅读与讲解自检，未复现实验。

## 一句话总结

BoT把跨层权重堆成三维张量：缩小时保留小波低频子带，扩大时把小模型当低频、补零细节后逆变换，为目标模型提供无需学习映射的初始化。

## 研究背景与动机

小到大常用复制或训练映射，大到小常用选择权重；作者希望用同一算子连接两个方向。将权重视作多分辨率信号是方法假设，不是神经网络知识必定集中于低频的普遍定理。[§1–2，PDF1–2]

BoT免训练指迁移算子不需额外可学习参数，目标模型后续仍需预训练或微调；源模型也已消耗训练成本。

## 方法总览

中文原创图依据Fig.2、§3及式1–4；Haar小立方体和尺寸是教学例，不是作者模型权重或默认小波配置。旧概览图由此图替换。

### 1. 迁移的是模型参数，不是把图像/文本输入缩放

输入为已训练源checkpoint和目标架构。输出为目标模型的初始化权重，随后仍需预训练或下游微调。迁移算子本身没有额外学习参数，不代表源训练、后续优化或目标推理免费。[§3，PDF3–4]

按功能将每层线性矩阵分别分组：注意力QKV、输出投影Wo、FFN的Wf1/Wf2。对相同功能，将L层矩阵沿层轴堆成 \(W\in\mathbb R^{L\times d_{in}\times d_{out}}\)。每组有自己的输入/输出维，不能将四组当成相同shape的四张图。底层框架可能以out×in存线性权重，必须先固定转置和axis规范，最后严格还原。[式3，PDF4]

教学若QKV合并为L×d×3d，源(12,768,2304)经每轴减半可到(6,384,1152)；Wo从(12,768,768)到(6,384,384)，FFN相应按自身矩阵维处理。这组例子只演示兼容的倍率，不宣称是论文所有配置。注意力头数、每头维度、Q/K/V排列和FFN膨胀率必须与目标定义一致，单纯元素个数匹配不足以保证模块语义相符。

### 2. 一维Haar先走通：低频系数不是普通平均值

采用正交归一化Haar作阅读补充，成对输入(a,b)分成 \(l=(a+b)/\sqrt2\)、\(h=(a-b)/\sqrt2\)。逆变换 \(a=(l+h)/\sqrt2\)、\(b=(l-h)/\sqrt2\)。这里l是平均趋势的**归一化系数**，不是(a+b)/2；不同小波和边界模式会改变实际系数。论文消融用多种小波，不能把Haar示例当所有实验默认。[§3.1、Fig.5，PDF3、7]

保留l、h可精确恢复；若只保留l并令h=0，重建为两份(a+b)/2，失去二者差异。它是信号子空间投影，不是保证神经网络函数保持的操作。较小目标直接继承l，与把它再次解码回两点是不同步骤。

### 3. 三个轴为何产生八个子带？

沿层、输入维、输出维各做低通L/高通H与下采样，每轴两种选择，组合共2³=8：LLL是近似cA，其余LLH、LHL、LHH、HLL、HLH、HHL、HHH为七个细节子带。正文只命名cD1…cD7，具体库中的字母轴序仍需固定。[式1–2、Fig.2，PDF3]

若三维均为偶数、滤波/延拓允许相应尺寸，每个子带约为(L/2)×(din/2)×(dout/2)。总系数数仍约等于原张量，因为八个子带合起来没有压缩；**丢掉七个细节才减少所保留信息**。层轴高频是相邻层权重变化，不是图像纹理频率；通道轴高频也不是直接可解释的视觉高频。

### 4. 贯穿一个2×2×2立方体：具体丢了什么？

教学按顺序把0…7放入一个权重立方体，各轴用上述正交Haar。其LLL系数
\[
 cA=\frac{0+1+\cdots+7}{\sqrt8}=\frac{28}{\sqrt8}\approx9.899495.
\]

L2S得到的1×1×1目标值是9.899495，不是3.5。若把这个cA和七个0细节送回IDWT，大立方体每项才是 \(cA/\sqrt8=3.5\)。原参数的平方和为140，低频系数平方98，丢弃细节能量42；全八子带的平方和仍为140。这里能量守恒依赖所选正交Haar，不能照搬成所有双正交小波系数的欧氏范数恒等式。

还可反看尺度：小权重1作为cA扩大成八个值，每个为1/√8≈.353553；原来八个常数1缩小则成为√8≈2.828427。**S2L不是原值复制八遍**。归一化会改变逐项幅值，若未经核实再手工乘回√8，便改变了论文所述直接系数继承；代码是否另做尺度校正必须核查。

## 核心创新与关键设计

### 5. L2S：保留cA，拆回目标层，再训练目标

对每个源模块Wsrc，选分解配置、取cAsrc作为Wtgt。接着沿目标层轴切开为相应线性矩阵，按正确的QKV顺序和存储方向写入目标checkpoint。不同功能的模块各自做变换，不把注意力和FFN跨功能混滤。[§3.2、式3，PDF4]

更深分解会继续对近似子带下采样，留下更粗表示；它不保证低频包含任务全部信息，只是作者的初始化归纳偏置。后续训练继续更新目标参数，源模型不必像在线蒸馏那样每步参与前向。具体未迁移参数如何初始化，主文并未全部说明。

### 6. S2L：源权重当低频，零细节合成，不是恢复原大模型

令cA=Wsrc，按目标需要创建七个细节0张量，调用 \(W_{tgt}=IDWT_{3D}(W_{src},0,\ldots,0)\)，再拆回目标层。小模型没有保存大模型的那些细节，所以扩大只是低频一致的初始猜测，不能重建一个唯一的原始大checkpoint。[§3.3、式4，PDF4]

在匹配边界与Haar尺寸的理想条件下，“小→补零扩大→取低频缩小”可回到同一个小系数；而“大→取低频→补零扩大”只得到低通投影，通常无法回到原大张量。参数变换的局部可逆关系也不能证明Transformer含softmax、归一化和残差后的整体函数保持。

### 7. 形状适配是复现关键，不能用“任意大小”略过

单层标准DWT通常沿每个选定轴按2缩小，递归层级给2的幂倍率；例如深度只减半、宽度要减为原来的3/4，就不是统一三轴一次下采样能直接满足的目标。不同滤波长度/边界延拓还会改变系数长度。主文声称选分解层级精确匹配尺寸，但没有完整说明非同比例、非2幂及奇数长度怎么适配，不能默认裁剪/插值一定符合作者方法。

QKV合并有语义分块边界；长滤波器跨过Q/K/V边界或跨head位置，可能混合不同功能坐标。embedding、LayerNorm、bias、分类头/语言头、词表变化及共享权重也不都属于上述三维堆叠矩阵。应逐项记录“已变换/另规则迁移/保留随机初始化”，缺少规则不能直接宣称整个网络已按论文完整迁移。

### 8. 训练流程和计算成本

```text
读取只读源checkpoint → 校验功能分组与轴顺序
L2S：各组三维DWT → cA作为目标模块
S2L：源模块作为cA + 七个零细节 → 三维IDWT
按目标层拆分 → 检查全部shape/未覆盖参数 → 保存新的目标checkpoint
后续：预训练或直接下游微调；两种实验协议分别报告
```

滤波核长度固定时，一层可分离三维变换成本大致正比于参数元素数；多级近似分解的规模逐级缩小。它避免了额外可学习映射训练，不意味着不读写大checkpoint或不占中间内存。S2L输出目标本身就需大模型存储；峰值还依赖是否分组、流式写入及小波库缓存，主文没有统一延迟/显存预算。

FLOPs节省率比较达到同一目标性能的后续训练成本，不是让所有epoch的单步成本都下降。要复现实际收益需单列源模型训练是否已有/可摊销、初始化计算、目标后训练以及最终质量；直接微调和先再预训练的结果不能混为相同实验。[§4，PDF5–8]

### 9. 参数排列与替代设计的边界

相邻通道是人为索引，不是天然空间邻域。教学一维权重[1,1,−1,−1]的Haar低频为[√2,−√2]；重排成[1,−1,1,−1]后低频为[0,0]。单个序列重排不自动保函数，但网络可通过相邻层补偿神经元置换而保持相同函数，权重频谱却会变化，因此低频“知识”依赖参数坐标规范。论文未据此证明对所有等价网络排列不变。

与选择/复制、蒸馏或学习映射相比，BoT提供便宜且双向的初始参数生成，但不提供通用函数保持。小波家族消融显示依任务和方向选择不同，不能把某个最好家族写成统一最优。此笔记只独立验证Haar算术、形状与读文逻辑，未变换任何真实模型checkpoint或训练模型。

视觉用ImageNet-1K，6层DeiT-S与12层DeiT-B互转、150epoch；语言用BERT与GPT2的6/12层，语料包含英文Wikipedia，GPT另加BookCorpus。[§4，PDF5–7]

| DeiT | 39.0% | 22.0% |
| BERT | 52.8% | 67.1% |
| GPT | 31.0% | 58.3% |

## 局限与讨论

神经元置换后网络函数可等价，但邻接权重频谱会变化，小波低频的语义依赖参数排列；正文未充分解决这个不变性问题。源模型预训练开销是否可摊销对实际节省很关键。范围集中于同族Transformer，不能据此承诺跨任意架构保性能。

有限实验与曲线不构成函数保持证明；小波家族、边界规则和维度处理影响数值尺度及训练稳定性。
