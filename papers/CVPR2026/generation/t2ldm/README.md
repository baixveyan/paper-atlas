# A Self-Conditioned Representation Guided Diffusion Model for Realistic Text-to-LiDAR Scene Generation

核对日期：2026-11-07。正文与配图按v2重审。以下实验均为作者报告；本地完成原文阅读与讲解自检，未复现实验。

## 一句话总结

T2LDM用训练期重建引导网络和方向角编码增强LiDAR扩散模型，并用3D框构造可组合文本描述；推理只保留去噪网络。

## 研究背景与动机

文本-LiDAR配对数据比文本图片少，模型容易生成平滑、缺细节的点云。文本越精细又会把有限数据切成稀疏组合，因此复杂描述未必更可控。Range Map把球面铺平，还可能使街道方位与接缝混淆。[§1–3，PDF1–4]

### 1. 先理解生成对象：二维距离网格，不是直接生成N个无序点

原始点 \(p=(x,y,z)\) 带回波强度I，距离 \(r=\sqrt{x^2+y^2+z^2}\)。球面投影按水平角与仰角放入Range Map：两个通道是距离r和强度I。nuScenes样本为32×1024×2，KITTI-360为64×1024×2；实现采用通道在前时，批量形状可写为B×2×H×W。网络最后输出同尺寸RM，再按每个像素对应的射线及距离恢复3D点。[§4.1、§5.1，PDF3–5]

式1的水平坐标为 \(u=\tfrac W2[1-\operatorname{atan2}(y,x)/\pi]\)。教学点(10,0,0)的距离10、u=512（W=1024），点(0,10,0)同距10但u=256。若实现floor取格，两个点落在不同水平方向；这不是把x或y直接线性缩放为图像坐标。每个格只能存有限回波，因此遮挡、同格碰撞、视场外点与无效距离使投影仅部分可逆；碰撞保留规则、无效值、距离归一化不能由图尺寸推断。

原文垂直式使用`arcsin(z/r)+f_up`并以f归一化，DPE又用上下视场端点插值；不同库对f_down正负和行方向的约定不一。复现必须核查两式与传感器FOV的对应关系，不能凭常见公式偷偷换符号。下文角度教学只按式5的网格定义，不将其冒充已核实的完整投影/逆投影实现。[式1、5，PDF4–5]

### 2. DN接收什么：噪声RM、时间、文本与方向

训练先取干净RM \(x_0\)、随机步t及高斯噪声ε，组成 \(x_t=a_t x_0+\sigma_t\epsilon\)，其中 \(a_t=\sqrt{\bar\alpha_t}\)、\(\sigma_t=\sqrt{1-\bar\alpha_t}\)。这是解释条件DDPM的标准闭式记法。t在1024个训练噪声层级中采样；噪声RM与原RM同形状，不能把“1024步”理解成1024条LiDAR线。[§4.1，PDF4]

冻结CLIP把文本编码为 \(F_{text}\in\mathbb R^{n\times768}\)。DN是U-Net，多尺度阶段含残差块与注意力块。将某层空间特征展平为 \(F_{noise}\in\mathbb R^{l\times C_D}\)，其中l=h×w，投影成Q∈R^(l×C)；文本投影成K、V∈R^(n×C)。
\[
 W=\operatorname{softmax}_{text}(QK^\top/\sqrt C),\quad
 O=\operatorname{mlp}(WV)+F_{noise},\quad F=\operatorname{ffn}(O)+O.
\]

每个位置用一行权重汇总n个文本token，所以W是l×n，WV是l×C；输出投影必须与残差通道相容。注意力并不是把整句文字复制到每个点坐标。时间和DPE进入残差块以说明当前噪声程度和射线方位；CLIP冻结，但DN中的条件投影和注意力属于要学习的部分。无条件模式用自身噪声特征代替文本特征进行相应注意力，不能一律想成把K/V设零。[§4.4、式7，PDF5]

### 3. v预测到底预测什么，怎样用于一步去噪？

DN输出 \(v_\theta(x_t,t,c)\)，其目标不是原点云坐标，也不是时间导数随意定义的速度。式2的具体v转换推导在补充材料；以下采用常见v参数化作阅读补充，与主文式9的 \(\epsilon=\sigma_t x_t+a_t v_\theta\) 一致：
\[
 v=a_t\epsilon-\sigma_t x_0,\qquad
 \widehat x_0=a_t x_t-\sigma_t v_\theta,\qquad
 \widehat\epsilon=\sigma_t x_t+a_t v_\theta.
\]

原因是 \(a_t^2+\sigma_t^2=1\)，两式构成一个二维正交变换，逆变换可直接恢复x0和ε；不需要把v当成新的观测传感量。教学取a=.8、σ=.6、x0=.5、ε=−1，得到xt=−.2、v=−1.1。反求x0=.8×(−.2)−.6×(−1.1)=.5，反求ε=.6×(−.2)+.8×(−1.1)=−1。

训练 \(L_{DN}=\mathbb E\|v-v_\theta\|^2\)。采样时只有xt、t、文本，无干净x0；预测v后换算噪声，代入式9的DDPM均值，再按当前层级加入相应随机项，逐步得到x(t−1)。初始xT是随机噪声，最终生成RM后才反投影为点云。条件/无条件交替训练支持CFG；本文未在所读主文给出完整条件丢弃率、引导尺度和所有采样配置，不能自行声称只要用某固定CFG就复现。[式2、9，PDF4–5]

## 核心创新与关键设计

### 4. GN不是外部预训练教师：它从同一数据学习重建细节

仅凭去噪目标，稀缺Text-LiDAR训练对可能不足以让DN学好小物体。作者额外搭一个与DN类似、编码器和解码器各四阶段的GN。**训练时GN输入干净RM x0**，还接收DN的多尺度噪声特征；它重建x0，得到几何细节特征 \(F_{recon}\)。这里的“真实坐标”由RM表示，不是额外再喂一个无序N×3点数组。[§4.2、§4.4、Fig.3，PDF4–5]

接口可写为 \(\widehat x_{GN}=x_\phi(x_0,F_{noise})\)，目标 \(L_{GN}=\|x_0-\widehat x_{GN}\|^2\)。GN内部注意力融合DN对应尺度的特征，使辅助网络的重建表示适应当前DN，而不只是固定的外部视觉教师。随后以SCRG对齐GN的重建细节特征和DN噪声特征。[式3–4]

主文把 \(l_{recon}\) 标为余弦相似度，却以“特征相减”作简写，并未完整展开取负/1−cos、各尺度归约及归一化维度。为理解对齐方向，可用常见 \(1-\cos(u,v)\) 作教学：u=(1,0)、v=(0,1)时为1；方向对齐后为0。把原始cos直接当正号损失最小化会鼓励反向，不是预期的对齐；真正实现的符号、零向量稳定项与权重应查代码。此例只讲优化意图，不补造作者精确loss实现。

### 5. 梯度时间表：GN冻结与GN不参与计算是两件事

总训练目标为 \(L=L_{DN}+L_{GN}+\lambda L_{SCRG}\)，λ是按epoch变化的因子，详细日程在未读补充中。CLIP始终冻结；GN只在前100K步参与参数更新，之后固定；DN继续学习。[§4.5、式8，PDF5]

前期GN与DN共同适配，GN不断接收变化中的DN特征并学习重建。后期“GN冻结”表示不再更新φ，并不等于训练时完全删除GN或对其输入一律`no_grad`；固定网络仍可能对输入传递梯度。主文没有完整给出DN→GN边的detach、对齐目标是否stop-gradient、各项损失对两网络的具体梯度路由，所以不能把上述语义写成一套确定的autograd代码。复现时必须逐边核验，避免误让DN收到或失去辅助梯度。

推理则明确删除GN：只有DN、所需文本条件和DPE参与生成。GN训练中看到x0属于监督；推理绝不能用测试真值RM去“提供几何先验”。“无推理成本”只指相较同样DN无需额外跑GN，不表示1024步采样或文本编码无需计算。[Fig.3实线/虚线、§4.5]

### 6. DPE逐步展开：给矩形网格补上角度身份

RM把360°展开成矩形，接缝两侧在3D可能相邻，在图像横坐标却相距很远。DPE为每层h×w位置定义角度：
\[
 \theta_i=2\pi-2\pi(i+.5)/w,\qquad
 \varphi_j=f_{up}-(f_{up}-f_{down})(j+.5)/h.
\]

i是列索引、j是行索引，.5表示格中心；水平角采用式5自己的0到2π约定，与式1的atan2方位需按固定角度原点核对。再对k=0,…,K−1拼接 \(\sin(2^k\theta),\cos(2^k\theta),\sin(2^k\varphi),\cos(2^k\varphi)\)，每个位置得到4K维多频特征。[式5–6，PDF5]

教学w=4，则θ从第0到第3列是7π/4、5π/4、3π/4、π/4；第0列最低频水平sin/cos为(−√2/2,√2/2)。θ接近0与2π时sin/cos接近，能提供环形方向身份，而整数列号没有这种周期性。K=2时角度特征宽度8。若当前隐藏特征通道C≠4K，必须有相容的投影/通道安排才能相加；原文未展开所有投影、门控α的形状与初始化，不能直接把8维广播成任意C。

注入写作x'=x+α·DPE。可学习α允许模型控制角度先验的影响，既不是对输入点云强行旋转，也不是显式修改邻接边。DPE能帮助辨识方位，但不自动把普通卷积改成环形卷积，更不证明所有跨接缝拓扑错误被消除。输入的扫描方向、视场或传感器变了，还需重新核验角度与RM的对应。

### 7. 文本可控性的训练分布与算力边界

T2nuScenes从34149个样本的3D框构造car数量、关系、朝向以及天气/时间描述，维度分别存储以组合。具体而稀有的相对位置会把有限样本划成更零散的小组；作者将某些描述改成“around”等较粗条件以增加每组覆盖，不是免费提高同一精度的定位能力。[§3、Table1，PDF3]

流程是“点云→RM与文本配对→DN去噪+GN重建/对齐训练→移除GN进行扩散采样→RM反投影→检测框和文本匹配评价”。TBR的判定依赖生成点云上的检测器，漏检或错框会改变匹配率；它不能当作对所有物体关系的人工几何真值检验。

DN多尺度空间特征的cross-attention权重大小为l×n；GN训练还带来特征融合、重建前向和早期反向开销，不能只比较推理参数30.4M就推断训练更省。1024次采样每次要跑DN，CFG若双分支还改变实际前向数，本文未提供可据此推导通用延迟的测量。Table8的30k迭代质量优势说明收敛收益，不能直接改写为端到端推理快若干倍。预训练固定GN和端到端方案的差异由Table9支持，但也不能把其他教师架构一概判无效。[PDF8]

## 实验与关键结果

nuScenes32线RM为32×1024×2，KITTI36064线为64×1024×2。每种方法生成10000样本，真实分布用全部34149或76165样本；必须统一FID参考集，不能与随机子集统计混用。[§5，PDF5–8]

| KITTI360无条件 FSVD/FPVD | 31.82/35.94 | 21.12/25.39 |
| nuScenes无条件 FSVD/FPVD | 86.54/83.97 | 64.21/62.85 |
| nuScenes文本 FSVD/FPVD | 91.15/88.55 | 66.93/65.84 |

文本可控率TBR/TBK原文记号混用，Table4本文23.44%，Text2LiDAR17.15%。有改善但离完全匹配仍远，不能写成任意文本精确控制。[PDF7]

物体位置细描述匹配率12.23%，调整为较粗的around描述后23.42%；这是任务变粗与数据分布变化后的结果，不能当相同约束下精确定位加倍。

## 消融实验与证据强度

Table7文本生成，无DPE/SCRG为FSVD73.64、匹配19.32%；仅DPE71.32/20.95，仅SCRG68.45/22.15，完整66.93/23.44。两项在该设置互补。[PDF8]

30k步KITTI360，完整FSVD47.29、仅DPE91.32，支持早期收敛收益；两者推理参数30.4M和1024步相同。Table9预训练GN为68.77，无SCRG68.11，端到端64.21，说明不是随便加一个冻结教师就有效。

## 局限与讨论

文本模板以car为主要目标，复杂关系与稀有天气场景仍受训练分布限制。RM投影只部分可逆，碰撞、缺失点与传感器线束差异需处理。生成分布指标变好不直接证明自动驾驶下游安全或真实传感物理准确。

其他条件任务需额外训练条件编码器，不能宣传全部任务零训练。补充材料中的训练权重日程与详细检测器协议未核验。

建议 `data/lidar/t2ldm/`，数据和生成点云不纳入仓库。本地未训练或运行模型。
