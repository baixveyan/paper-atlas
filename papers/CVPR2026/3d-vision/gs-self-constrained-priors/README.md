# 3D Gaussian Splatting with Self-Constrained Priors for High Fidelity Surface Reconstruction

作者：Takeshi Noda, Yu-Shen Liu, Zhizhong Han。

分类：3d-vision；交付形式：Markdown 中文论文讲解。

核对日期：2026-11-07（方法与配图v2返工）。以下实验均为作者报告；本地完成原文阅读与讲解自检，未复现实验。

## 一句话总结

把当前高斯场渲染的深度融合为TSDF，再用这个自生成距离场清理、移动和约束高斯，使几何重建更贴近表面。

## 研究背景与动机

渲染好看不保证表面准确；单凭二维颜色、多视角一致性容易留下漂浮高斯或过度平滑。引入外部深度网络又带来尺度对齐与域偏移。本文选择周期性利用当前模型自身的几何估计，构成可收紧的局部约束（第1–2页）。

## 方法总览

![自约束高斯表面重建：TSDF、透明度与投影时序](../../../../site/figures/gs-self-constrained-priors-method-v2.svg)

已有多视角RGB与相机→优化平面高斯→渲染深度→融合TSDF→查询每个高斯的距离→约束透明度、显式拉回位置并清除离群。TSDF周期更新并收紧带宽，不是额外训练一个神经SDF，也不是外部真实深度监督。[主文PDF3–4]

## 核心创新与关键设计

### 1. 输入输出、符号和坐标

输入I个已标定视图与相机，学习M个高斯的中心、方向/尺度、颜色与透明度，最后输出新视角图像或由深度TSDF提取的表面。论文采用平面高斯以利几何表达，不是任意体积高斯天然都有明确表面。[PDF3–4]

| 量 | 形状 / 含义 | 用在哪里 |
| --- | --- | --- |
| 图像与相机 | 每图H×W×3；内外参 | 渲染、反投影与跨视图对应 |
| 中心μj、透明度oj | 三维位置、[0,1]标量 | 查询TSDF、优化及合成 |
| 深度di' | 每图H×W，按相机Z定义 | TSDF融合，不是射线欧氏距离 |
| ft | 三维网格上的截断符号距离 | 插值得sj=ft(μj) |
| σt、δt | 截断带宽与带内表面分区阈值 | 两者不是同一个阈值 |
| εj、有限差分步长ϵ | 样本权重、空间位移 | 两种符号不能混用 |

所有中心必须与网格使用一致坐标和尺度。相机Z深度与沿斜射线距离不等，若直接混用融合会错；例如针孔反投影可用ZK⁻¹[u,v,1]ᵀ，这是理解深度接口的基础补充，不是论文完整融合实现。

### 2. 自先验怎样形成：渲染深度，再融合为冻结参考

式1以splatting算子渲染高斯相机坐标的Z值，颜色则用相同合成框架渲染RGB。式2为 \(f_t=\mathcal F(\{d_i'(t)\})\)，即当前各视图深度融合。零水平集为当前估计表面，归一化截断值在[-1,1]，σt控制实际窄带宽度。[PDF3]

周期性重新融合，使用更新后的深度代替旧参考，同时减小带宽，第8页讨论1→.5→.25的尺度。σ不是网格中必须出现的唯一距离值，δ也不是世界单位上的额外全局半径。缩带让监督更局部，但若初始表面错，可能把正确但尚未恢复的结构排除。论文没有完整列更新迭代号、体素大小、融合权重与所有初始化时序，此处不补猜。[PDF3、8]

参考来自自己的深度，并不提供新的外部证据。它将多视角估计融合为一致的几何约束，可能比单视图稳定，也可能把共同的错误固化。周期更新是交替过程；不能直接称为端到端反传穿过所有TSDF融合的神经场训练。

### 3. 查询中心与透明度约束：分区决定梯度方向

对每个μj在网格中做三线性插值，取 \(s_j=f_t(\mu_j)\)。8个体素角按位置分数加权，而非只选最近体素；位置查询不等于检查整个高斯椭球的所有覆盖。主文把sj恰为±1的高斯视为带外离群，而不是把所有sj非零都删除。未观测体素、越界查询及浮点饱和值容差没有完整指定，需实现核验。[PDF3–4]

剩余高斯分 \(N_{on}=\{j:|s_j|\le\delta_t\}\)、\(N_{off}=\{j:\delta_t<|s_j|\le1\}\)。目标是近表面高透明度、离表面低透明度：

\[L_{SCP}=\frac1M\left[\sum_{j\in N_{on}}\epsilon_j(o_j-1)^2+\sum_{j\in N_{off}}\epsilon_jo_j^2\right],\qquad\epsilon_j=\frac1{(1+|s_j|)^2}.\]

M是高斯总数，不是两个集合各自单独归一。相同透明度下，离零面越远权重越小，但分区改变目标值；“距离远”不意味着该项惩罚更大。教学δ=.2、o=.4：sj=.1时权重≈.82645，未除M的损失≈.29752；sj=.6时权重.390625，损失.0625。对应透明度导数分别为 \(2\epsilon_j(o_j-1)/M\) 与 \(2\epsilon_jo_j/M\)，所以梯度下降让前者升o、后者降o。[PDF4式3]

若透明度由sigmoid参数化，还要链式乘激活导数，不能把对o导数直接当优化器底层参数导数。上述推导只解释该约束；颜色重建、遮挡和其他损失同时作用，最终o并非一定恰为0或1。

### 4. 显式位置拉回：有限差分与尺度前提

主文式4用中心差分估计梯度，每轴 \(\partial_x f\approx[f(x+\varepsilon)-f(x-\varepsilon)]/(2\varepsilon)\)，\(\varepsilon=10^{-4}\)；中心查询一次、三轴各两个邻域查询。随后按式5显式更新

\[\mu_j\leftarrow\mu_j-s_j\nabla f_t(\mu_j).\]

这是增密之后的直接位置操作，不是每次训练中另加一个pulling loss。它会改变下一轮渲染的几何，且不自动同步重置优化器动量；具体状态处理主文未交代。[PDF4]

阅读补充：若f为真实单位梯度SDF，平面z=0、f=z，在μz=.2处s=.2、梯度1，更新到0。但归一化TSDF通常还涉及σ：教学f=z/σ、σ=.5，μz=.1处s=.2、梯度2，直接按印刷式变为−.3，会越过平面。原式未显示梯度归一化、除以梯度范数平方或反归一化，不能宣称任意TSDF下都“一步精确投影”。完整代码须确认距离单位、坐标缩放和梯度处理；本篇不悄悄修改成另一个投影算法。

在截断饱和区梯度可能为0，拉回不一定有效；随后再清除带外点正有必要。网格粗、薄结构双面接近、有限差分跨不连续边界也会影响方向。真正的原文安排是**增密→拉回→清除仍带外点**，不是先删除再试图把已删点拉回来。[PDF4，Constraint Scheduling]

### 5. 其余损失如何抑制厚表面与视图不一致

每条射线上U个高斯的交点深度ρu和alpha合成权ωu构成

\[L_{Depth}=\sum_{u=0}^{U-1}\sum_{u'<u}\omega_u\omega_{u'}(\rho_u-\rho_{u'})^2.\]

同一可见表面若由前后多层贡献，惩罚促其沿射线收薄。权和为1时，此式等于加权深度方差；权和不是1时，需保留原始权重尺度，不能直接当标准概率方差。教学两深度1、3，权.5/.5，值为1；深度都2时为0。遮挡后另一个真实表面也可能在射线上，因此透明度和有效可见性影响这种收薄的适用性。[PDF4式6]

法向项LNS比较高斯渲染法向与由深度导出的法向，L1差乘 \(\eta=(1-\|\nabla I\|)^2\)。它倾向让两种几何线索一致，但容易过平滑。该权重依图像梯度的归一化范围，平方式也不保证在任意未归一化范围内单调抑制边缘，不能自行给未说明的截断实现。

跨视图再用局部平面的单应 \(H_{rm}=C_m(R_{rm}+T_{rm}n_r^\top/\tau_r)C_r^{-1}\)，n和τ为参考相机中的平面法向与距离；平面方程的符号需与相对位姿配套。将参考像素hr投到邻视图再回参考，LNM惩罚 \(\|h_r-H_{mr}H_{rm}h_r\|_1\)，只在有效像素集合V上平均。[PDF4式7–9]

单应坐标是齐次的，工程实现通常还需除以第三坐标再比较像素，印刷式未完整展开。若Hmr是Hrm的精确代数逆，往返本来恒等，无法提供新的几何监督；实际约束应来自不同视图分别估计的局部几何和有效性判断，具体构造需代码核验。遮挡、深度不连续、非平面大区域都可能破坏局部单应假设。

### 6. 一轮训练走通与停止条件

总目标 \(L=L_{RGB}+.01L_{Depth}+.1L_{NS}+.1L_{NM}+.01L_{SCP}\)。RGB项采用MAE、SSIM和多视图NCC，原文未把全部子权重和窗口设置展开。高斯参数随渲染损失更新，当前TSDF提供周期保持的参考，未训练额外SDF网络或深度先验模型。[PDF4式10]

一轮可理解为：选视图、渲染RGB/深度/法向→计算各项→优化高斯；每次增密后按先拉回后剔除；到参考更新周期时重新渲染多视图并融合、收窄σ。论文未给完整事件重合时的执行优先级，以上按已明示依赖解释，不冒充可执行训练器。结束后渲染深度并按2DGS同设定TSDF融合提取表面；“提取表面的TSDF”与“优化期参考TSDF”角色不同。[PDF3–5]

M个高斯查询/拉回约O(M)，每个有限差分要多个网格插值；稠密TSDF网格若为Gx×Gy×Gz，存储随三轴乘积增长。周期融合还涉及多视图深度和体素投影，不能只按O(M)宣称总流程线性或比PGSR更快。作者DTU报告42分钟对PGSR40分钟，重建精度与时间应分开比较。

## 实验与关键结果

第5页NeRF-Synthetic表1：CD_L1×100为1.87、PSNR34.21，对比PGSR2.18/34.05。第6页DTU平均CD0.50、时间42分钟，对比PGSR0.53/40分钟；TNT平均F1为0.51对PGSR0.50。并非逐场景最优，例如DTU场景83为1.06，PGSR1.01更好。Mip-NeRF360室内PSNR30.56也低于GOF30.79。

## 消融实验与证据强度

第8页DTU表5：无自先验CD0.56，全方法0.50；去透明度约束0.53，去投影0.51，去离群删除0.53。仅初始场0.54，逐次更新至0.50；固定带宽1/0.5/0.25为0.54/0.53/0.51，渐进收紧0.50。支持各组件，但差值较小，原文未提供多种子误差条。

## 局限与讨论

自约束可能强化错误的初始深度；TSDF分辨率、相机标定和窄带会影响薄结构。无需外部数据驱动几何先验不等于无需相机与多视角。作者平均指标改善不代表所有渲染指标或场景领先；时间也未优于全部基线。

## 复现提示

应记录TSDF网格、截断距离、更新周期、增密与清理时序。总损失深度/法向/跨视角/透明度权重分别0.01/0.1/0.1/0.01（第4页）；表面提取遵循2DGS的TSDF设置。项目页GSPrior在论文第1页给出，尚未核验代码版本、许可证和硬件可复现性。
