# 3D-Aware Multi-Task Learning with Cross-View Correlations for Dense Scene Understanding

作者：Xiaoye Wang, Chen Tang, Xiangyu Yue, Wei-Hong Li。

分类：recognition；交付形式：Markdown 中文论文讲解。

核对日期：2026-11-08。正文与配图按v2重审。以下实验均为作者报告；本地完成原文阅读与讲解自检，未复现实验。

## 一句话总结

通过独立的跨视图几何分支和代价体增强多任务特征，在单图部署时也改善分割、深度、法向和边界预测。

## 研究背景与动机

多任务共享二维特征可能学到相互矛盾的空间线索；简单加入视频帧并不等于利用对应关系。作者将立体匹配的几何表示接入现有MTL编码器，避免几何匹配与主语义分支直接竞争（第1–3页）。

## 方法总览

中文原创图依据Fig.2、§3.2和式2–3。相机、深度采样、点积与缓存数字是教学例，不是作者数据；新图补充原稿未展开的几何路径。

### 1. 先区分主MTL特征和几何分支

给参考图Ii及邻图Ij，主编码器f分别提取多任务共享语义特征；另一路CvM并行处理图像。CvM=g=e∘m∘s：浅ResNet式CNN s先提几何偏置特征，Swin式多视图变换器m交换上下文，e再构造深度代价体。它不是把主MTL特征再直接当匹配描述子，以免两类学习目标过度干扰。[Fig.2、§3.2，PDF4]

默认V=2个视图，每视图RGB输入逻辑形状B×3×H0×W0。CvM特征为B×128×h×w，h=H0/8、w=W0/8；变换器有6层自/跨视图注意力。主MTL特征可能有自己的空间尺度与通道数，最终拼接需对齐空间，主文未完整列出各骨干重采样/投影规范，不假定任意两个张量可直接concat。[§4.2，PDF6]

### 2. 自视图注意力与跨视图注意力在做不同事情

self-attention汇集同图局部结构，cross-attention使参考位置读取邻图上下文；作者采用类似Swin的窗口限制，重复跨层/尺度信息交换。它增强匹配描述子，但不等于已硬指定了每个像素的正确对应。遮挡、重复纹理或运动物体仍可能引入错误关联。[PDF4–5]

多于默认两视图时，论文对较多邻居的跨视图注意力只选相机距离最近的两个作折中；不要把“所有图构造代价体的平均”与“每次attention读取所有邻居”混为同一规则。窗口大小、跨层交互与边界处理主文未给全。

## 核心创新与关键设计

### 3. 逆深度候选：代价体的一条轴是深度假设

设L个候选，先在逆深度ρ=1/d均匀取值，再换回d。教学近端d=1、远端d=4，L=3，逆深度[1,.625,.25]对应深度[1,1.6,4]，不是线性深度[1,2.5,4]；它给近处更密的深度采样。[§3.2，PDF5]

作者配置L=128，并写候选范围0.0001到10；这些数对应的具体单位/实现采样端点和逆深度转换需查代码，不补成已校准的所有场景米制范围。深度候选只是一组可供匹配的假设，不是外部真值深度，也不是直接把深度网络输出离散化。

### 4. 从参考像素到邻图：一次warp逐步怎么计算？

阅读补充使用常见针孔模型：参考像素齐次坐标p=(u,v,1)，内参Ki；假设相机Z深度为d，则三维参考点 \(X_i=dK_i^{-1}p\)。相对位姿若按“参考→邻图”定义，\(X_j=R_{ji}X_i+t_{ji}\)，再以Kj投影并除Z得到邻图采样点。于是
\[
 p_j(d)\sim K_j\big[R_{ji}(dK_i^{-1}p)+t_{ji}\big],\qquad
 \widehat F_{j\to i}^{(d)}(p)=F_j(p_j(d)).
\]

右侧通常用可微双线性采样，结果落回参考像素网格。它不是将邻图特征直接平移若干格，也不是逆用相机外参而不核对方向。图像缩到特征分辨率时内参焦距/主点也要对应缩放。主文没有完整规定采样align_corners、遮挡/越界mask、相机尺度校准等实现细节，以上是解释warp的数学约定，不是作者函数签名。[式2、PDF5]

教学两相机无旋转，参考到邻图的平移为(−b,0,0)，焦距f=100像素、b=.1、参考横坐标u=50，则邻图位置u'=u−fb/d。d=1时取u'=40，d=2时取45。参考像素同一个，深度不同会去邻图不同位置找相似特征；这正是深度代价体能携带几何信息的来源。相机符号若反过来，位移方向也反，不能只背“减去视差”。

### 5. 点积如何从两张特征图变成h×w×L代价体？

对参考像素每个d，用通道归一化点积评价匹配，再平均邻居：
\[
 C_i(p,d)=\frac1{V-1}\sum_{j\ne i}
 \frac{F_i(p)^\top\widehat F_{j\to i}^{(d)}(p)}{\sqrt K},\qquad K=128.
\]

每个点积把K维变成一个标量，枚举L个深度后C形状为B×L×h×w（文中写h×w×L）。它叫cost volume，但这里是相似度：较大通常更匹配，不可误当越小越好的距离。主文没有在此处直接规定对深度softmax取期望作为最终深度图，而是将整条L维曲线交给任务头。[式2，PDF5]

教学改用K=2便于计算，参考特征(1,0)，d1邻图特征(1,0)，d2为(0,1)，两分数分别1/√2≈.7071和0。分数不是已经归一化的概率，也不证明d1必是真深度；无纹理或重复纹理可能让多种深度都高分，多视图平均也可能被遮挡污染。

### 6. 融合与监督：代价体既服务深度，也服务其他任务

每视图拼接 \(\widetilde F_i=\operatorname{concat}(f(I_i),C_i,F_i)\)，若空间已对齐、主干有Cm通道，则融合通道逻辑上为Cm+L+128。分割、深度、法向、边界等各自任务头ht读取同一增强表示，按对应任务标签与loss训练。代价体没有独立替代所有任务头。[式3、Fig.2，PDF4–5]

公式对f、g和各头联合最小化任务loss；实现沿用基础MTL方案的loss和权重，不能凭拼接结构自行添加“逐像素3D一致性损失”当成作者目标。相机warp和点积能传梯度到CvM特征，但相机/深度假设是否学习、基础编码器具体冻结哪些参数要按实现确认，不因它使用预训练骨干就认定全部冻结。[PDF5–6]

NYUv2额外视频帧只有深度标注，不是每帧都有完整分割/法向/边界真值。因此loss须按实际存在的标签计算；具体混合采样和缺失标签mask仍需核查，不能把缺失任务标签当零背景训练。[§4.1，PDF5]

### 7. 单图复制：输入能运行，不等于新观测产生了视差

单视图训练/测试时将同一图复制为邻图。它保留双路网络接口，但原文没有给全重复图相机参数处理，不能直接声称复制等于真实双目。[PDF5]

重要的教学退化：若同时采用相同内参、R=I、t=0，则 \(p_j(d)\sim K(dK^{-1}p)\sim p\)，任何候选深度都取同一位置。如果两路特征也相同，C(p,d)沿d就是重复值，没有可辨识视差曲线。若实现选择别的伪相机或增广，需要另说明；复制本身并不提供真实第二视角几何。

复制设置的性能收益可来自辅助架构、特征交互和训练归纳偏置，不能解读为单图已经观测出真实双目深度。作者关于抑制伪相关的说法是待进一步分析的假设，不是由复制操作推出的定理。

### 8. 内存/时间与复现边界

教学480×640输入，1/8特征为60×80，L=128，则每视图代价体有614400个标量，float32仅该张量约2.34MiB；双视图、梯度、128通道特征和注意力另计。若天真地将所有深度的warp特征一次物化，还要再乘K通道，峰值远大于最终代价体。分块是否实现、dtype与内存复用主文未详述，不能凭约5M参数说运行成本可忽略。

对所有参考/邻居/深度的匹配计算约随V(V−1)LhwK增长（具体邻居选择依实现），窗口attention另有开销。增加候选或视图会加算力但不保证指标单调提升。相机误差、动态物体、跨帧遮挡、深度尺度不一致、重复图退化是具体失败路径。本文只验算相机/点积/形状，不加载模型、估计COLMAP或训练多任务网络。

## 实验与关键结果

第6页多视图训练/单图测试：DINOv3+视频mIoU64.03、深度RMSE0.3954，本文65.27/0.3836，法向15.35持平。单视图表2为64.98/0.3909，相比DINOv3 63.68/0.4113。NYUv2训练795/测试654；PASCAL4998/5105。CvM约5M参数，对300–350M编码器约1.5%，不是对任意骨干都可忽略。

## 消融实验与证据强度

第7页去全部几何分支深度0.3954，仅代价体0.3853，仅跨视图0.3856，全0.3836；全模型法向15.35不及部分变体15.32。第8页视图数2/3/4对应ΔMTL19.05/19.20/18.63，非越多越好；深度候选128/512为19.05/19.25，256/384更差。不同表ΔMTL基准不同，不能直接混算。

## 局限与讨论

依赖训练相机估计与静态对应，动态物体会破坏匹配。单图复制的收益不证明真实几何可辨识；参数少不代表代价体内存与运行耗时小。128维、1/8分辨率、6层注意力和128深度平面是本文配置而非最优性证明。
