# A Closed-Form Solution for Debiasing Vision-Language Models with Utility Guarantees Across Modalities and Tasks

核对日期：2026-11-03。以下实验均为作者报告；本地完成原文阅读与讲解自检，未复现实验。

## 一句话总结

用群体文本原型的差向量定义属性子空间，在其平行与正交分量之间选择去偏嵌入，以几何界约束效用损失；保证范围限于表示空间。

## 研究背景与动机

直接投影掉“男性医生/女性医生”等完整原型，可能同时删除“医生”的任务语义。作者改为原型之间的差，试图集中移除属性变化；图像与文字共享空间，因此分类和检索需要同时处理两端。[Fig.1、§3，PDF3]

公平性在此被定义为对各群体原型相似度相等或接近，这是一个可优化替代量，并不囊括现实公平的所有定义。

## 方法总览

![属性差子空间、二维折中与归一化目标的中文几何详解](../../../../site/figures/closed-form-vlm-debias-method-v2.svg)

方法依次生成群体提示、求文本原型、取原型差构成属性子空间，再将待处理的单位图像/文本嵌入分为属性与正交内容两部分，闭式选择折中系数并输出仍在单位球上的向量。编码器冻结，不增加一个需下游标签训练的分类头。[正文§3–4，PDF3–5]

本次补读官方附录A后，旧稿的公式疑点有了明确来源：**闭式解使用归一化后的两项损失，正文式4仍打印未归一化形式**。下面从实际目标逐步推导，分别标出两种问题，不把它们称为同一个最优解。[补充PDF3–6]

## 核心创新与关键设计

### 1. 输入、群体与共享空间

输入为已有VLM的单位嵌入e∈R^d、当前语义提示及n个属性群体。图像/文本编码器的输出先ℓ₂归一化；输出u仍为d维单位向量。所谓neutralization，是u对当前所有群体文本原型的相似度相等；这是一种表示层公平替代量，不能涵盖所有实际公平定义。敏感群体可以是性别、年龄或交叉组合，但分组集合本身由任务定义，模型不能自动识别遗漏群体。[§3]

| 对象 | 形状与含义 |
| --- | --- |
| 每群体锚点与m个变体 | (m+1)条文本，各经冻结文本编码器得到d维单位向量 |
| 原型矩阵P | d×n，第g列为群体单位原型pg |
| 原型差矩阵D | d×(n−1)，列为pg−p1 |
| 子空间正交基Q | d×r，r≤n−1；QR/SVD是阅读建议，未核验作者求解器 |
| e∥、e⊥与u | 均为d维；两分量正交，u最后重新组合而不是丢失维度 |
| a、b、α | 两分量长度及新属性系数，标量；a²+b²=1 |

不是直接对人输出某个敏感属性判定，而是在给定原型定义下调整表示。原型构建依赖提示和LLM，虽无需额外下游训练标签，也不能称为完全无先验。

### 2. 从群体提示得到属性差，为什么不投影完整原型

围绕当前提示，例如“医生照片”，先构造含群体的锚点，再生成保持其余语义不变的同义表达。冻结文本编码器计算eg与变体e_g^(i)，原型为归一化和：
\[
p_g=\frac{e_g+\sum_{i=1}^m e_g^{(i)}}{\|e_g+\sum_{i=1}^m e_g^{(i)}\|}.
\]

它对应单位球上最大化与这些样本总余弦的方向；不是把锚点独占一半权重，再把变体平均占一半。若变体个数变化，锚点相对权重也变化；若向量和接近0需要保护。提示改写可能带入年龄或其他词义，因此作者要求保持非属性内容，仍需检查实际生成文本。[正文§4.1；补充B，PDF6]

令D=[p₂−p₁,…,pₙ−p₁]，属性空间A=span(D)。因为
\[
\langle u,p_g\rangle=\langle u,p_1\rangle\iff\langle u,p_g-p_1\rangle=0,
\]

只需u正交于差空间。完整原型往往还包含“医生”等共同语义，直接正交于它们张成的空间可能同时去掉这部分。

二维教学例：p₁=(.8,.6)、p₂=(.8,−.6)都是单位向量；差为(0,−1.2)，所以A是纵轴。原型本身张成整个二维平面，若把整个平面去掉只剩零向量；差空间投影却能保留横轴上的公共内容。这个例子只阐明线性几何，不声称真实CLIP概念正好对应坐标轴。

### 3. 投影后先量长度，再把搜索压成一个标量

若Q是A的正交基，则\(e_\parallel=QQ^Te\)、\(e_\perp=e-e_\parallel\)。正文写A(AᵀA)⁻¹Aᵀ，要求基列满秩；不能把所有可能相关的原型差直接求普通逆。记a=‖e∥‖、b=‖e⊥‖，归一化方向\(v_\parallel=e_\parallel/a\)、\(v_\perp=e_\perp/b\)。

固定分量长度时，Cauchy–Schwarz说明与原分量同向能最大化⟨u,e⟩，因此可在这两个方向内搜索，而不是在d维单位球遍历。对一般非退化a,b>0的有效折中，
\[
u(\alpha)=\alpha v_\parallel+\sqrt{1-\alpha^2}v_\perp,\quad0\leq\alpha\leq a.
\]

其范数为1；残余泄漏L(α)=α，自效用损失
\[
V(\alpha)=1-\langle u,e\rangle=1-a\alpha-b\sqrt{1-\alpha^2}.
\]

在此区间L递增，\(V'=-a+b\alpha/\sqrt{1-\alpha^2}\)从负到0，V递减。α=0是去掉该属性空间后归一化，损失1−b；α=a还原原向量，损失0。所谓Pareto曲线是两者互有取舍，不存在同时把两项一般地降到0的点。[正文Lemma1–2；补充A，PDF1–3]

纯公平权重端点会有多个同样最优方向，所以正文“每个最优解都在二维平面”的全称表述在效用权重为0时应谨慎理解；对本文选择的非退化归一化平衡点，上述同向参数化足以得到目标解。

### 4. 两项归一化是闭式公式的必要前提

正文先写w₁L+w₂V，权重非负且和为1，再取最坏权重。对任意固定α，最坏加权和等于max(L,V)。但是附录证明第4页明确**先把每项按自身最大值缩放**，实际求
\[
\min_{0\leq\alpha\leq a}\max\left(\frac\alpha a,\frac{1-a\alpha-b\sqrt{1-\alpha^2}}{1-b}\right).
\]

归一化后泄漏从0到1、自效用损失从1到0，在交点唯一平衡。设E=a+(1−b)/a，令两项相等得到
\[
\frac\alpha a=\frac{V(\alpha)}{1-b}
\ \Longrightarrow\ b\sqrt{1-\alpha^2}=1-E\alpha.
\]

平方前需保留右侧非负条件。展开并用a²+b²=1：
\[
(E^2+b^2)\alpha^2-2E\alpha+a^2=0,
\quad
\alpha_\star=\frac{E-b\sqrt{E^2-a^2}}{E^2+b^2}.
\]

取减号根且检查0≤α≤a、1−Eα≥0；加号根来自平方后的另一支，不能只凭二次方程任挑一个。最后合成u(α⋆)。由交点直接得\(V(\alpha_\star)=(1-b)\alpha_\star/a\)，无需额外神秘假设。[正文Theorem1；补充A，PDF4–6]

归一化改变了优化目标，附录的“hence”不是与原始数值目标等价的代数变换。因而准确的结论是该闭式解对**归一化两项的最坏权重折中**成立；它并非对所有固定偏好都最优。源码本次未读，本文只核实论文的证明与数值，不推断源码是否遗漏归一化。

### 5. 贯穿算例：输出向量、泄漏、效用都算出来

延续属性纵轴例子，取原e=(.8,.6)，于是e∥=(0,.6)、e⊥=(.8,0)，a=.6、b=.8。E=.6+.2/.6=.933333，按闭式
\[
\alpha_\star\approx.2391598,\qquad
u\approx(.9709802,.2391598).
\]

点积⟨u,e⟩≈.9202801，V≈.07971994；归一化泄漏α/a和归一化损失V/.2都约.3985997。完全移除属性则u=(1,0)、V=.2；不变则u=e、L=.6。平衡点比完全投影保留更多表示效用，但仍残留属性分量。

两个群体相似度也可直接核算：⟨u,p₁⟩≈.9202801，⟨u,p₂⟩≈.6332883，差≈.2869918=1.2α⋆。这说明“平衡去偏”没有完全满足相似度相等；不能把α⋆>0方案叫严格完全中和。

若改为原始min max(L,V)，二分求交得α≈.1291901，和.2391598不同。旧稿只说“待复核”的数值差异本次已定位到附录新增归一化；保留两个问题的区别，而非把原闭式当错误计算。[本地教学例与标量数值核对，不是作者实验]

### 6. 跨模态界如何由向量位移得到

单位向量满足\(\|u-e\|^2=2(1-\langle u,e\rangle)=2V\)。在图像与文字点积差中加减⟨eI,uT⟩，再用三角与Cauchy–Schwarz：
\[
|\langle u_I,u_T\rangle-\langle e_I,e_T\rangle|
\leq\|u_I-e_I\|+\|u_T-e_T\|
=\sqrt{2V_I}+\sqrt{2V_T}.
\]

这个界控制相似度变化，未直接控制分类F1、检索Recall或个体公平。两端都用上例V时界约.79860，可能很松；实际点积差必须另外测量。若某任务所有候选分数误差均≤ε，只有原top1间隔>2ε才能据此保证该次top1不翻转，这是阅读补充而非论文提供的无条件任务保证。[正文Proposition1；补充PDF1]

### 7. 退化输入、训练与部署成本

a=0意味着e已正交属性空间，保留e即可；b=0时正文Proposition2选择保留纯属性语义，这是一种保效用约定，不能声称同时满足完全公平。属性秩0、秩亏、接近零的分量以及a很小时(1−b)的消减误差都需数值处理；QR/SVD阈值、ε及是否使用有理化公式须查代码。本文不猜作者阈值。

该方法不微调VLM权重：原型生成、投影、标量闭式属于表示后处理。分类按类别文本语义构建相应原型并处理图像/文本后比较；检索按查询语义处理两端；生成只处理文本表示，原文的文本编码接口适配仍需具体模型代码，不能把任意token序列替换为一个d维向量就称实现。

每组原型需n(m+1)次文本编码，差矩阵分解约O(d n²)，有正交基后单嵌入投影约O(dr)，不必显式存d×d投影矩阵。若不同查询定义不同A，图库去偏也可能需要重新计算，不能把“无需训练”当成没有在线成本。商业LLM是作者原型构造配置，本地阅读与数值验证不调用它。

### 8. 替代设计与失败边界

完整原型投影可能删掉共享语义，差空间投影更有针对性；完全投影α=0中和更强，归一化平衡点牺牲部分中和换表示相似度。固定权重、按任务调参或学习去偏映射解决不同偏好问题，不是同一任务无条件优劣。若群体词变体本身带来语义偏差，差空间也会混入内容；交叉群体遗漏、原型几乎重合、图像/文本空间不完全对齐都会限制效果。保证只相对当前表示与原型成立，不把真实人群身份简化为模型感知标签。[正文Limitations与补充A–B]

## 消融实验与证据强度

Flickr MS@1000：仅锚点13.4、仅变体均值14.1、完整11.8；仅图像13.4、仅文本13.3，双模态更好。CelebA最大EO差，完整40.1，单图像41.7、单文本41.1。替换DeepSeek/Gemini的结果接近默认配置，支持原型构造在所测模型上较稳定，不能保证所有提示都无差异。[Table5，PDF8]

对手方法RoboShot的CelebA公平数值23.3/40.0略优于本文23.6/40.1，不能把“各项都最佳”照搬为笔记结论。

## 局限与讨论

作者明确：保证的是几何空间内语义一致性，不直接保证F1、Recall@K。原型质量、敏感群体定义、非二元与交叉群体覆盖、感知属性标注误差都会影响解释。[Limitations/Ethical Statement，PDF8]

本次补读附录A证明与B提示，仍未核验代码中的退化向量、秩亏子空间及数值稳定实现。群体词与感知标签不是个人身份自我认同。

## 复现提示
