# 240FPS Stereo Vision from Monocular Mixed Spikes

作者：Yeliduosi Xiaokaiti, Yakun Chang, Yang Bai, Zhaojun Huang, Peiqi Duan, Boxin Shi。

分类：imaging；交付形式：Markdown 中文论文讲解。

核对日期：2026-11-08。以下实验均为作者报告；本地完成原文阅读与讲解自检，未复现实验。

## 一句话总结

通过镜面与分光器把两个视角混合到一台脉冲相机，再用显示调制和时空网络重建高时间采样率双目视频；240FPS描述输出采样，而非已验证的整套实时吞吐。

## 研究背景与动机

高速双目通常需要同步两台相机；脉冲传感器的高频二值输出有潜力降低硬件同步成本。这里的“单目”指单传感器，光路仍包含左右两个视角，因此不能理解成普通单张RGB恢复可靠双目深度（第1–3页）。

## 方法总览

![240FPS Stereo：脉冲积分解混、跨视图和时序融合详解](../../../../site/figures/240fps-stereo-method-v2.svg)

两个光学视角在**同一像素处叠加强度**，其中右路经过周期LCD调制，脉冲相机记录混合光。先逐像素解一个两未知数线性系统得到左右粗图，再由SMS-Net校正亮度、去除串扰和融合历史细节。标题中的单目是单传感器，不是单视角输入。[Fig.1–5，PDF1–6]

## 核心创新与关键设计：从脉冲时间到左右两幅图

### 1. 为什么单传感器仍有左右视差

直接光路提供左视角，45°平面镜把另一个视角反射到分光器，与直接光叠加；LCD只衰减反射一路。光路的等效相机位置不同，因此有双目几何信息，而相机输出没有左右图的独立空间分区。要解开它，利用的是两路不同的**时间调制系数**，不是把传感器左右两半各裁一张照片。[§3.3、Fig.5，PDF6]

透过率f(t)、每像素阈值Q与光电转换α需要已知或标定。输入是每像素触发时间序列{t_i}，并非普通RGB帧或事件相机的正负亮度变化事件。脉冲像素积分光子，到阈值就触发1并清空；低亮度时脉冲少，长时间没有触发也不自动意味着光强正好0。镜面带来的深度位移要求专门几何标定，主文把细节放在补充；后面的极线attention与深度估计都依赖正确对应。

### 2. 每个脉冲间隔提供一个积分方程

在某一像素省略x/y，主文式1–4可重写为：

\[Q+\eta_i=\alpha[I_L\Delta t_i+I_RF_i],\qquad \Delta t_i=t_i-t_{i-1},\qquad F_i=\int_{t_{i-1}}^{t_i}f(t)\,dt.\]

Q是一个触发间隔积分的电子量，Δt是时间，f无量纲所以F也有时间量纲；两列系数分别控制未调制和调制视角。η合并离散触发误差和局部光强不恒定的模型误差，不是已知可直接扣除的噪声。关键近似是短窗T_w内I_L/I_R可当常数，否则每个间隔都是不同未知量，仅增加方程数也无法解固定两个数。[PDF3–4]

教学归一化Q=α=1，第一间隔Δt=.5、F=0，得到.5I_L=1；第二间隔Δt=.25、F=.125，得到.25I_L+.125I_R=1。先算I_L=2，再得I_R=4。第二段平均透过率F/Δt=.5，与第一段0不同，所以能区分两路。所有数只是积分模型的手算，不是实际曝光秒数或相机标定参数。

### 3. 最小二乘、正则与真正的可辨识条件

把n个间隔堆成A∈R^(n×2)，第i行为α[Δt_i,F_i]，b=Q·1_n，x=[I_L,I_R]^T。主文在式5上加λ=10⁻³的L2正则：

\[\widehat x=\arg\min_x\|Ax-b\|_2^2+\lambda\|x\|_2^2,\qquad (A^\mathsf TA+\lambda I)\widehat x=A^\mathsf Tb.\]

这是2×2正规方程，可以累计∑Δt²、∑ΔtF、∑F²及右端项，不必为每像素建立巨大的通用矩阵。梯度2A^T(Ax−b)+2λx=0导出上式；正λ稳定病态系统，也会把估计向0收缩，未必无偏。主文没有明确非负约束、饱和裁剪、低脉冲数回退或α/Q的单位归一，不能自动把它当非负最小二乘。

**f(t)随时间变化不是任意窗口都可解的充分条件**。两列必须不成比例，即选中间隔的平均调制F_i/Δt_i有足够变化。若所有行都满足F_i=.5Δt_i，就只能约束I_L+.5I_R，(2,0)和(1,2)是同一组合；即便大范围f波形在变化，当前脉冲间隔恰好取相同平均也仍可能退化。λ让数值矩阵可逆，不会凭空创造缺失观测。只有一个或没有有效完整间隔、低照或小调制深度都使问题更难。论文称调制保证独立，理解时须附上这个采样/秩条件。[PDF4]

### 4. ABC：用整周期混合图校正左右特征的亮度统计

每个目标时间t还有过去一完整调制周期T_f的混合脉冲计数图：

\[M_t=\frac Q{T_f}\sum_{k:t_k\in(t-T_f,t]}1.\]

按每像素计数得到H×W图；它保留混合强度的周期统计，不是干净左图或右图，也不是瞬时光强真值。完整周期能平均调制的相位差，但物体运动、光源变化与计数边界误差不会自动抵消。实际刚启动时需积累整周期或规定边界策略，正文未给首周期处理。[式6，PDF4]

在尺度s，编码出左右和M特征，工作形状均B×C_s×H_s×W_s。ABC分别求左特征/M特征每通道空间均值与标准差，形成4C_s项统计，经两个1×1卷积预测γ、β，再做Fbar_L=γ_L·F_L+β_L；右分支同理。γ/β通常沿空间广播，这只是维度解释，主文没有完整层宽。它是**学习出的仿射校正**，并非直接用(特征−均值)/标准差代替原特征的固定AdaIN公式；共享M参考不表示左右特征必须变成一模一样。

### 5. CBA：沿对应极线读另一个视角，抑制跨路残影

解混粗图会保留另一视角的边缘串扰。左右视角真实物体对应有几何视差，而串扰位置和纹理可能不一致；CBA在每个尺度采用SCAM跨视图attention交换信息。[Fig.3，PDF4–5]

在校正成立的同一极线工作记法下，一行左特征可形成Q_L∈R^(W_s×d)，右侧K_R/V_R覆盖该行W_s位置，softmax(Q_L K_R^T/√d)的W_s×W_s权重让每个左位置聚合右侧候选，右向左也类似。这是SCAM的形状解释，不是主文新增实现公式。不是简单逐像素左右相加，也不需要已经知道唯一视差；重复纹理、遮挡或标定偏差仍会混淆对应。正文未列QKV通道、视差范围mask或所有残差连接，不能把这段写成可直接替代作者模块的代码。

### 6. RSF：先把历史对到当前，再在同位置的时间轴做attention

低透过率相位右路纹理弱，单帧不够恢复，因此保留左右历史状态队列。Fig.3画前3帧，公式以一般长度ℓ表示；以当前尺度的左支为例，历史状态ℓ×B×C×h×w先通过可变形卷积对齐到当前：

\[\widetilde S_{t-i}^L=\operatorname{DeformConv}(S_{t-i}^L,\Delta,m),\qquad \theta_p=\operatorname{softmax}(Q_pK_p^\mathsf T/\sqrt d),\quad G_t^L(p)=W_o\sum_{i=1}^{\ell}\theta_{p,i}V_{p,i}.\]

Δ是学习到的空间采样偏移，m是调制mask；它们由网络估计以补偿运动，不是真实光流或LCD的f(t)。每个空间位置p的当前特征投成1×d的Query，已经对齐的ℓ个历史状态成为ℓ×d Key/Value，所以权重为1×ℓ。这里只在该位置的**历史时间维**softmax，不把所有hw个像素两两做全局时间空间attention。[Fig.4、式7–8，PDF5]

教学d=1，Q=1，K=[0,ln3]，softmax分数权重[.25,.75]；若V=[2,6]，加权结果5。权重大只表示网络在当前Query下更偏好该历史表示，不代表该帧一定无遮挡。未对齐时同一位置可能已经是另一个物体，attention就可能把错误纹理带回来；deformable alignment和visibility处理并非可省细节，主文没有解释完全遮挡时如何保证无伪影。

GTA结果G与当前Ftilde沿通道拼接，经ECA通道注意增强得到E_L/E_R，再用SCAM做左右融合，形成Fhat_L/Fhat_R。图中还把当前输出push进状态队列、pop最旧项， shared decoder恢复左右精修图。左右共享decoder不是将左右输出强行设相同。队列到底存哪一尺度/是否跨片段清零、初帧空历史如何padding、截断反传长度，主文未完全展开。

### 7. 训练与推理的梯度边界

合成数据先对TartanAir左右视频插帧，再对右路乘f(t)、与左路叠加，模拟积分触发得到mixed spikes；KITTI也构造测试子集。两路原图是网络监督，不能把模拟输出当实拍真值。SMS-Net最终只列左右L1：L=||Ihat_L−Igt_L||_1+||Ihat_R−Igt_R||_1，训练更新encoder、ABC、CBA、RSF、decoder参数。[§3.2–3.3，PDF5–6]

DEFOM或CREstereo是后接的**冻结现成视差估计器**，用精修左右图计算视差/深度以评估解混有无几何价值；主文没有额外深度训练损失。所谓网络end-to-end也不能扩展成LCD、Q/α、最小二乘λ和下游估计器都被联合学出来。作者AdamW、lr10⁻⁴、余弦退火、300epoch、batch12、4090，与本地仅阅读/算例核对须分开。

```text
已标定的单传感器混合脉冲 + 已知调制f(t)
→ 每像素短窗收集完整触发间隔，构造两列系数并正则最小二乘
→ 左右粗图；另由一周期混合脉冲计数得到M_t
→ 多尺度编码 → ABC亮度仿射 → CBA极线跨视图交互
→ RSF历史对齐 + 逐位置时间attention + ECA + 再次SCAM
→ 更新历史队列，shared decoder给左右精修图
→ 可选冻结双目估计器给视差/深度，不参与上述L1训练
```

### 8. 240FPS、延迟与复杂度的不同口径

原型LCD60Hz，每周期约16.67ms解出4组左右图，输出时间格间距约4.17ms，等价240组/秒采样位置。脉冲读出40kHz的二值时间网格不等于每个像素都以40kHz触发，亮度才决定触发率。短窗数据与整周期M_t还有输入支持跨度，所以输出时间戳间距不能当总延迟。[PDF2、4]

逐像素LS只解两个未知数，但收集脉冲/累计积分遍历全图全窗；ABC统计约C_s H_s W_s；极线attention约H_s W_s²d，GTA在对齐后约ℓhwd，另有deform conv、encoder/decoder和队列显存ℓBChw。CPU构造约.093s、求解.0151s的作者分项计时已经远大于4.17ms，网络与搬运还没计入；本文没有端到端240FPS实测吞吐保证。

更短窗更接近瞬时光强，却减少脉冲数和调制变化；更长窗更好求解但更易违反恒亮/无运动近似。加大λ可稳定病态却偏向低强度；更长历史提高纹理候选却增加对齐错误与缓存。两台同步相机可避免解混近似，但需额外传感器同步和标定；这才是本文单传感器光路方案的实际取舍。

## 实验与关键结果

训练使用TartanAir插帧与脉冲仿真，KITTI及实拍作测试；AdamW、学习率10⁻⁴、300轮、batch12、RTX4090。第7页表1中TartanAir配DEFOM的AbsRel由粗图0.1695降至精修0.0940，RMSE由2.5187降至1.7852；真实左右图对应上限0.0498/1.5839。KITTI对应RMSE 4.8843→4.1719。单目基线只用一个视角且涉及尺度对齐，不能视为输入完全公平的比较。

## 消融实验与证据强度

第8页表2中左右PSNR从26.53/16.54升至36.97/35.73，支持解混后继续精修的必要性。但全部模块并非每个指标最优：ABC+RSF的bad3=4.691优于全模型4.791；TartanAir上的CRE深度RMSE还出现2.2064→2.3595退步。

## 局限与讨论

60Hz调制器、低照度不足的脉冲数、光路标定和运动近似都是限制。第4页CPU线性系统构造约0.093秒、求解0.0151秒，不能由240FPS标题推导出端到端240FPS实时部署；论文也承认高速实时实现仍待解决。

## 复现提示

应先复核光路、调制曲线、标定与脉冲模拟，再验证网络。分别记录输出时间间隔、单阶段耗时和端到端延迟。论文给出MonoSpikeStereo项目入口，但此次未执行其代码；实拍没有在本地采集。

## 相关工作与阅读顺序

先了解脉冲相机积分触发模型，再读结构光/调制成像与双目匹配。DEFOM、CRE在这里是下游深度估计器；理解其输入差异，才能判断重建改善是否转化为几何改善。
